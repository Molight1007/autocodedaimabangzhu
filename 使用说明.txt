autoCode 使用说明
================

本项目只有两个版本，共用同一套底层（autocode/app、engine、llm、store、prompts），
但各自独立启动、独立数据库、互不影响。

一、完整版（本地单人用）
========================
启动：双击 启动.bat（桌面窗口）或 autoCode-browser.bat（http://127.0.0.1:8765）
功能：全部功能——导入、生成测试数据、对抗数据、参考解、提示、题解、
      逐行解析、自测判题、校验、导出。
数据：data/autocode.db
密钥：右上角「设置」填 API Base 与 Key；File/key.txt 是本地回退，不会上传。
系统：Windows 10/11（需 WebView2，Win11 自带）、Python 3.10+。
首次运行 启动.bat 会自动创建 .venv 并安装 requirements.txt。

二、精简版（服务器 / 多人共用）
==============================
启动：双击 启动-精简版.bat  →  http://127.0.0.1:8767
功能：只做三件事——导入并切题、生成测试数据、按错解生成对抗数据。
      不含提示、题解、代码解析、判题与导出。
数据：data/slim2.db
账号：管理员 autocode；学生用学号登录（一人一号，花名册由管理员导入）
密码：管理员首次启动随机生成，写在 data/slim2-initial-password.txt，登录后请删除该文件。
改密：.venv\Scripts\python.exe -m autocode.slim2.passwd

与完整版的实现差别（不是界面裁剪，是生成方式不同）：
  1. 切题只标行号，题面由程序从原文切片，模型改不了字；
  2. 先写代码答案，再生成输入，最后让另一段独立上下文复核；复核方看不到生成理由，
     算不准会标「不确定」；
  3. 期望输出由代码答案在评测机上逐条真跑得出，不让模型口算；题面有样例时
     代码必须全过样例才算「已锚定」，没有样例也照常执行，只标「未锚定」；
  4. 对抗数据必须真跑学生代码，卡不住或用例不稳定的直接丢弃。

精简版首次使用
--------------
1. 双击 启动-精简版.bat，浏览器打开 http://127.0.0.1:8767
2. 用户名 autocode；密码见 data/slim2-initial-password.txt
3. 顶部切到「导入」页：
   - 把 PDF / Word(.docx) / 图片(PNG·JPG·WebP) / TXT / Markdown 拖进虚线框，或点击选择；
     抽文字与切题一次完成，解析结果直接列出来
   - 图片（截图、手机拍照）由多模态模型转写成文字；模型名统一填 deepseek-flash，
     文字 / PDF / Word / 图片都用它，不必来回换
   - 旧版 .doc（Word 97-2003）请先用 Word/WPS 另存为 .docx；服务器装了 LibreOffice 时会自动转
   - 也可以把题面粘贴进文本框，点「开始切题」
     样例标签支持【样例输入】、样例输入：、输入样例、示例 1 输入：、Sample Input 等写法
   - 切完表单会收成一行「已识别 xxx · 切出 N 道题」，点「重新导入」可重来
4. 勾选要入库的题 → 「确认入库」→ 自动跳回题库并打开第一道
   - 入库前先在页面上方「入库到」选题库：
     · 默认题库：最多 100 道。每次确认入库都会先检查数量，超出时自动删掉
       最早入库的题，只保留最新的一批。所有账号都能在默认题库里加题、删题。
     · 永久库：管理员点左上角「+ 永久库」新建，不设题目上限，任何操作都不会
       自动删题；只有管理员能在里面加题、删题，学生只能看题和生成数据。
   - 自动清理不弹确认、不列清单，连同该题的测试数据与对抗数据一起清掉
   - 入库前会提示「本次会移出几道」；被移出的题学生看不到、也不能再生成数据，
     正开着这道题的学生会自动回到题库并看到「已被移出题库」
   - 永久库里的题不会被自动清掉；管理员删除时仍按第 8 条的确认规则
5. 打开题目 →「生成测试数据」（会调用模型，按对话次数计费）
   - 生成完显示：通过复核多少条、被剔除多少条、代码实跑了几条
   - 体积上限（防刷库/拖垮执行）：单条输入 ≤12.8 万字符、2 万行；整批输入 ≤19.2 万字符；
     输入+输出 ≤64 万字符；超过会让模型缩小规模重来。实测 9.2 万字符（2 万个整数）
     校验 0.02 秒、执行 0.01 秒，系统本身不是瓶颈——能不能跑完取决于题目的算法复杂度
   - 题面残缺（少于 300 字、或完全没提输入/输出格式）时，会先让模型**补全题面**：
     只补输入格式、输出格式、数据范围与样例格式，原文逐字保留。补全后照常走
     「样例锚定 + 独立复核」。补过的题在题目页会显示黄色提示条，可展开看原文，
     也可点「恢复原文」一键还原（样例与契约会一并作废，需重新生成）
   - 模型说补不了（例如只有标题、不知道要算什么）才会失败，报「补全题面」失败原因
   - 题面没解析出样例也能生成，但代码答案没有样例可锚定，数据可信度会降一档：
     题目页会显示「样例 0 组」并给出说明，生成结果里标「未锚定」
   - 题面无样例、但按契约重写出的样例通过了代码答案时，结果里会写
     「未锚定（题面无样例，转写样例 N/N 通过）」——那不是没验过
   - 入库后某一层缺数据（比如压力层被契约校验全剔掉），结果里会写「入库后分层覆盖不足」
   - 需要恢复"没样例就不许生成"的严格模式：设环境变量 AUTOCODE_SLIM2_REQUIRE_SAMPLES=1
   - 提示条里的「代码实跑 N 条」就是执行验证的结果；「复核一致」是第二票
   - 代码答案跑不起来会带着报错重写一次；两次都失败就整题失败，不产出可疑数据
   - 数据页右侧「导出 JSON / 导出 CSV」把当前版本的数据连同题面、样例、
     对抗数据一起下载；CSV 带 BOM，Excel 直接打开不乱码
6. 切到「对抗数据」页，选语言、粘贴一份能通过样例的错解，点「生成对抗数据」
   - 样例就错的代码会被直接拒绝（这类 bug 不需要对抗数据）
   - 结果按「哪份错解」分组：左边是错解全文（带行号，可复制），
     右边每条数据给出「输入 / 期望输出 / 学生实际输出」和「错误原因」
   - 错误原因由模型在生成数据时一并写出：点名哪一行/哪个变量被触发、输出怎么偏的
   - 不知道写什么错解：展开输入框上方的「不知道写什么错解？」，有常见 bug 类型
7. 生成中可点「取消」，任务会被终止且题目状态自动恢复为「已就绪」
   （页面刷新后仍会接管正在跑的任务，进度不会停在半路）
8. 删除题目：草稿题直接删；已有数据的题需要输入题目名称确认，连同测试数据、
   对抗数据、提交记录一起清除，无法恢复。永久库里的题只有管理员能删，
   学生看到的是置灰的「仅管理员可删除」
9. 不调模型的自测：.venv\Scripts\python.exe -m autocode.slim2.selftest
10. 清空题库：关闭服务后删除 data/slim2.db，重启即重建空库

填自己的 API Key（精简版）
--------------------------
点右上角「设置」：
  - API Key：只保存在服务器 data/slim2-settings.json（权限 600），接口只回传后 4 位
  - Base URL / 模型：默认 https://api.deepseek.com/v1 + deepseek-flash
    （deepseek-chat 是旧型号名，实测生成测试数据时会把输出预算烧空，不要再用）
  - 「测试连接」会真发一次最小请求（约 0.5~1 秒），确认通了再保存
  - 「清除已保存的 Key」会退回使用服务器环境变量里的 Key
注意：这是单账号共用，任何登录者都能改 Key；改坏了所有人一起不可用，
      请先「测试连接」再保存。

对外部署（精简版）
------------------
默认只监听 127.0.0.1:8767。对外提供访问时：

  1. 前面加一层 HTTPS 反向代理（Caddy/nginx），后端仍绑回环；
  2. 环境变量见 deploy/slim2.env.example，其中 ALLOWED_HOSTS 必须写上
     用户浏览器里实际输入的主机名，否则会 403；
  3. 反代后面设置 AUTOCODE_SLIM2_TRUST_PROXY=1，否则全站请求都算同一个 IP，
     一个人错 5 次密码会让所有人锁 10 分钟；
  4. 代码执行目前只有 AST 守卫 + 超时，公网部署需要容器化隔离。
