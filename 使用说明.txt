autoCode 使用说明
================
1. 系统要求：Windows 10/11（需 WebView2，Win11 自带）、Python 3.10+。
2. 双击 启动.bat：
   - 首次运行会自动创建 .venv 并安装 requirements.txt 中的依赖；
   - 以后直接打开桌面窗口，不需要命令行。
3. 模型配置：右上角「设置」填 API Base 与 API Key，保存后可「测试连接」。
4. 数据只保存在本机 data/autocode.db；File/key.txt 是本地密钥回退，均不会上传。
5. 浏览器版备用：autoCode-browser.bat（http://127.0.0.1:8765）。
